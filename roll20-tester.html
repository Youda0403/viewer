Roll20 CSS 매크로 테스터

롤20 채팅창에 직접 안 보내도 매크로가 어떻게 보일지 미리 확인할 수 있어요.

매크로 입력

입력하는 동안 옆 채팅창에 실시간 미리보기가 떠요.
예제 매크로 불러오기

허용되는 HTML 태그

허용되는 주요 CSS 속성

채팅창에서 안 먹히는 속성/값

  • display: flex / grid 와 그에 딸린 gap, align-*, justify-*, flex-*, grid-*
  • position: fixed / sticky, z-index (불안정)
  • transform, animation, transition, @keyframes
  • filter, backdrop-filter, clip-path, mix-blend-mode
  • cursor, pointer-events, user-select
  • -webkit-… 같은 벤더 프리픽스 전부
  • <script>, <style>, <iframe>, <form>, javascript: 링크

출처: Roll20 Wiki (CSS, Macros/Formatting), 커뮤니티 포럼 정리. 실제 Roll20는 화이트리스트 방식의 sanitizer를 쓰기 때문에 위 목록 외에도 새 CSS 속성은 대부분 잘립니다.

채팅 미리보기

아직 메시지가 없어요. 왼쪽에 매크로를 입력하면 여기에 미리보기가 나타나요.
